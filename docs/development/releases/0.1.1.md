# Payment Verifier 0.1.1

The five packages now use shorter names under `@1hubengineering`. Replace the
core and all installed adapters together. Export subpaths and the database schema
are unchanged.

| Previous name                      | Install at 0.1.1                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `receipt-verifier`                 | [`@1hubengineering/verifier`](https://www.npmjs.com/package/@1hubengineering/verifier/v/0.1.1)               |
| `receipt-verifier-storage-sql`     | [`@1hubengineering/storage-sql`](https://www.npmjs.com/package/@1hubengineering/storage-sql/v/0.1.1)         |
| `receipt-verifier-adapter-drizzle` | [`@1hubengineering/adapter-drizzle`](https://www.npmjs.com/package/@1hubengineering/adapter-drizzle/v/0.1.1) |
| `receipt-verifier-adapter-prisma`  | [`@1hubengineering/adapter-prisma`](https://www.npmjs.com/package/@1hubengineering/adapter-prisma/v/0.1.1)   |
| `receipt-verifier-provider-cbe`    | [`@1hubengineering/provider-cbe`](https://www.npmjs.com/package/@1hubengineering/provider-cbe/v/0.1.1)       |

The renamed Drizzle adapter targets Drizzle ORM `1.0.0-rc.5`; the old 0.1.0
adapter targeted `0.45.4`. See the [compatibility matrix](../compatibility.md).
Receipt matching does not confirm settlement or authorize fulfillment.

Source: [`fc9b4d0`](https://github.com/1hubengineering/payment_verifier/commit/fc9b4d0aa5bf4ee62dc6facd9fd5200bd1db6013).
All 525 local tests and [Node 24/26 hosted checks](https://github.com/1hubengineering/payment_verifier/actions/runs/44420597022)
passed. The installed registry consumer verified all five archives and exercised
receipt and durable-job workflows. The GitHub 0.1.0 archive is unchanged.

The npm release metadata records the original folder paths. Browse the
[published source tree](https://github.com/1hubengineering/payment_verifier/tree/v0.1.1/packages)
at the release tag or the
[renamed folders on main](https://github.com/1hubengineering/payment_verifier/tree/main/packages).
