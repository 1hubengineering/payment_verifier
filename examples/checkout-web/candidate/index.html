Upgrade to SDK 0.3.0

Review the reference policy and plan the upgrade across your backend and workers.

Upgrade from 0.2.0

Keep the existing store and back it up before upgrading. Replace all installed SDK packages together. Upgrade every SDK process that reads or writes expectations before registering newly accepted references.

Configure the receipt reference

Use the Telebirr Customer Note or CBE Reason / Type of service. The SDK compares the extracted text exactly. To expect a blank note, set referenceRequired: false with an empty reference. A nonblank, invalid or ambiguous note still fails.

Keep claims on 0.1.1

An active 0.1.1 store needs a tested, claim-preserving cutover. On 0.3.0, continue to use a version that accepts any newly registered reference formats before considering rollback.
